# Family Bill Calendar

Android install for the household bill calendar. Version 1.1.

Bills stay on the phone. This repository does not contain your bill list.

## Install

1. Open the [latest release](https://github.com/d4tx-ch/family-bill-calendar/releases/latest).
2. Download `family-bill-calendar.apk`.
3. Open the file. If Android asks, allow installs from your browser or Files app.
4. Launch **Family Bill Calendar** from the home screen. The icon is a calendar labeled Bills inside the app launcher as Family Bill Calendar.

The first build is published by GitHub Actions a few minutes after this repository is created. Refresh the releases page if the file is not there yet.
